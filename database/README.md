# Banco de dados (Supabase)

Responsáveis: Pablo e Guilherme.

Coloque aqui os scripts SQL na ordem em que devem rodar, por exemplo:

```
001_tabelas_politicos.sql
002_tabelas_comunidades.sql
003_politicas_rls.sql
```

Lembretes:
- Ative o RLS (Row Level Security) em todas as tabelas.
- Guarde só o mínimo de dados pessoais dos usuários (LGPD).
- Cada informação de político deve ter **fonte** (URL) e **data** de coleta.
